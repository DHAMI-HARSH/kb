# Setup Checklist

Use this checklist to ensure everything is properly configured.

## Pre-Installation
- [ ] Node.js 18+ installed (`node -v`)
- [ ] npm 9+ installed (`npm -v`)
- [ ] 500MB+ free disk space
- [ ] Stable internet connection

## Installation
- [ ] Repository cloned/downloaded
- [ ] Dependencies installed (`npm install`)
- [ ] No install errors in console
- [ ] `.env.local` created from `.env.example`

## Firebase Setup
- [ ] Firebase project created
- [ ] Email/Password provider enabled
- [ ] Google OAuth configured
- [ ] Web app created in Firebase
- [ ] Config values obtained
- [ ] `.env.local` populated with credentials

## Local Development
- [ ] Dev server starts: `npm run dev`
- [ ] No console errors
- [ ] App visible at `http://localhost:3000`
- [ ] Landing page displays correctly
- [ ] Navigation links work
- [ ] Can navigate to /articles

## Feature Testing
- [ ] Can access landing page
- [ ] Can view articles page
- [ ] Can search articles
- [ ] Can open article modal
- [ ] Can access sign in page
- [ ] Can access sign up page
- [ ] Can access password reset
- [ ] Chatbot icon visible

## Authentication
- [ ] Firebase initialized successfully
- [ ] Can create new account
- [ ] Can sign in with email/password
- [ ] Can sign in with Google
- [ ] Can sign out
- [ ] User profile shows in navbar

## Production Readiness
- [ ] All environment variables set
- [ ] Build completes: `npm run build`
- [ ] No build errors
- [ ] Production build runs: `npm start`
- [ ] All pages work in production build

## Deployment (Optional)
- [ ] Vercel CLI installed
- [ ] GitHub repository created
- [ ] Project pushed to GitHub
- [ ] Environment variables in Vercel/hosting platform
- [ ] Successfully deployed

## Customization
- [ ] Logo updated (if needed)
- [ ] Colors customized (if needed)
- [ ] Metadata updated (if needed)
- [ ] Content replaced (if needed)

## Final Checks
- [ ] No console warnings/errors
- [ ] Responsive design works on mobile
- [ ] All links functional
- [ ] Forms validate properly
- [ ] Error handling works
- [ ] Performance acceptable

## Optional Enhancements
- [ ] Set up analytics
- [ ] Configure backup
- [ ] Set up CI/CD pipeline
- [ ] Add monitoring
- [ ] Configure logging
