⚡ 5-MINUTE QUICK START:

Step 1: Install Dependencies
  npm install

Step 2: Create .env.local
  cp .env.example .env.local

Step 3: Add Firebase Credentials
  - Go to https://console.firebase.google.com
  - Create a project
  - Copy credentials to .env.local

Step 4: Start Development
  npm run dev

Step 5: Open Browser
  http://localhost:3000

2. Never share your .env.local file
3. Use NEXT_PUBLIC_ prefix for public variables only
4. Check console for errors if something fails


🐛 TROUBLESHOOTING:

Firebase errors?
  → Check .env.local has all credentials
  → Verify Firebase project is active
  → Restart dev server

Port 3000 in use?
  → npm run dev -- -p 3001

Dependencies won't install?
  → rm -rf node_modules package-lock.json
  → npm install
